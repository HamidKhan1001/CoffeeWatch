# Coffee Watch

Photo-led specialty coffee storefront with a real-time 3D scroll scene (photoscanned CC0 models).

## Run locally

```bash
python3 serve.py        # gzip + caching, http://localhost:4173
```

Debug: add `?p=0.5` to jump the 3D scene to 50% of its scroll path.

Credits: see `assets/models/CREDITS.txt` (all CC0). `assets/unused/` holds earlier video experiments.
